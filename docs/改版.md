# 改版

三件事：用起来少走弯路，顶栏和菜单收干净，样式换成统一的现代外观。数据表不动，`library.db` 不变。

## 一、更好用

### 添加接口的框挪到接口列表上面

现在粘贴 curl 的大框在页面底部，接口多的系统要滚很久。改成放在接口列表上方。平时只有一行高，占位文字「粘贴一条 curl，⌘↵ 添加」。聚焦后撑到 180px，失焦且为空时收回一行。

### 最近打开

侧栏搜索框下面加「最近」一组，列出最近打开的 5 个系统，按最后打开时间倒序。切系统时写入本机记录，和上次选中的系统放一起。有搜索关键字时不显示这一组。

### 全部收起 / 全部展开

接口列表标题行右侧放两个小按钮：「全部展开」「全部收起」。全部展开把该系统所有接口 id 写入打开集合；全部收起清空打开集合并把所有 id 写入关闭集合。切系统后清空。

### 用例框头部重排

标题放左边，操作放右边。标题仍是第一条 `#` 注释或「用例 N」。标题右侧灰字显示从 curl 里取到的主机名，例如 `scm-po.te.ddmc`；没有 curl 或解析不到就不显示。操作按钮平时淡色，鼠标移到框上才显示完整颜色。

### 复制整条接口

接口标题行右侧加「复制全部」：把该接口所有用例按顺序拼起来，用例之间空一行，写入剪贴板。多条用例要一起发给别人时用。

### 删除系统收进「更多」

「删除这个系统」从页面底部移到系统头部右侧的「更多」菜单里。菜单先只放这一项，以后要加「导出这个系统」也放这里。删除仍要确认。

### 业务域改成可选列表

业务域输入框换成下拉，选项是 `DOMAIN_ORDER` 里的十个加一项「自定义」。选「自定义」时出现文本框。已有数据里不在列表里的业务域照常显示为当前值。

### 状态提示自动隐藏

「已保存」「已复制」这类提示 2 秒后淡出。「保存失败」「读取失败」常驻，直到下一次成功。

## 二、顶栏和菜单

### 顶栏

左边：当前系统的面包屑 `业务域 / 系统名`，再跟一个灰字 `N 个接口`。没选系统时显示应用名。

右边从左到右：

- 保存状态点。绿点「已保存」，橙点「保存中」，红点「保存失败」。鼠标悬停显示文字。
- 「导入」按钮，样式改成次要按钮，不再是橙色主按钮。
- 齿轮按钮，点开设置弹层。

状态文字不再单独占一块。

### 设置弹层

齿轮点开一个小面板，点面板外关闭。内容：

- 外观：跟随系统 / 浅色 / 深色
- curl 底色：颜色选择器，旁边一个「恢复默认」
- 字号：12 到 32，加减按钮和数字
- 数据位置：显示 `library.db` 所在目录，旁边「打开目录」

所有项改动立即生效并写入本机记录。

### 原生菜单

用 Tauri 2 的菜单 API 在 Rust 里建应用菜单，三端一致：

- 文件：导入 Markdown `⌘⇧I`，保存 `⌘S`，打开数据目录
- 编辑：系统默认的撤销、剪切、复制、粘贴、全选
- 视图：搜索 `⌘K`，放大 curl 字号 `⌘=`，缩小 curl 字号 `⌘-`，全部展开 `⌘⇧E`，全部收起 `⌘⇧W`
- 帮助：关于 OpenApi

菜单项触发时通过事件发到前端，前端执行对应函数。快捷键在前端已有的 keydown 里也保留，两边只做一件事，不重复触发。

## 三、样式

### 色板

用 CSS 变量统一，浅色和深色各一套。

浅色：

- 页面底 `#f4f1ea`
- 卡片 `#ffffff`
- 边框 `#e5e0d6`
- 正文 `#1e1c19`
- 次要文字 `#777068`
- 强调 `#c46b3a`，悬停 `#b25e30`
- 侧栏底 `#1f2a25`，侧栏文字 `#eef0ec`，侧栏次要 `#9fb0a6`，侧栏选中 `#2f4038`

深色：

- 页面底 `#161a18`
- 卡片 `#1f2522`
- 边框 `#2c3430`
- 正文 `#ebeae6`
- 次要文字 `#9a9890`
- 强调 `#d98552`
- 侧栏底 `#111513`，侧栏选中 `#26302b`

curl 底色和字号仍由用户单独设置，不随外观切换。

### 字体和尺寸

正文 `-apple-system, "PingFang SC", "Segoe UI", "Noto Sans SC", sans-serif`，14px。标题 20px，字重 600。圆角统一：按钮 8px，输入框 8px，卡片 12px，用例框 10px。卡片阴影 `0 1px 2px rgba(0,0,0,.05)`，深色下不画阴影只画边框。

### 侧栏

搜索框右侧显示 `⌘K` 小标签。业务域标题改为全大写小字加字距。系统项选中时左侧 3px 强调条，接口数放到右侧小圆角标签里。命中的接口行缩进 18px，方法用三个字母小写，路径截断。

### 接口行

方法徽标改成浅底深字：GET 绿、POST 蓝、PUT 橙、PATCH 紫、DELETE 红、其他灰。展开时整张卡片左侧 3px 强调条，标题行底部一条分隔线。鼠标悬停标题行底色微变。

### 用例框

头部和代码区同一深色，头部略浅一级。操作按钮无边框、小号，悬停才显色。框与框之间 10px。代码区保留现在的语法色。

### 按钮

主按钮橙底白字，次要按钮白底边框，危险按钮红字无底。高度统一 32px。禁用态 50% 透明。

### 空状态

没选系统时居中显示：应用名、一句话、两个按钮「导入 Markdown」「新建系统」。

### 细节

- 滚动条 8px，圆角，滑块半透明。
- 所有输入框聚焦时 2px 强调色外圈。
- 过渡 120ms，只用在底色和颜色上。

## 实施顺序

1. 色板变量和外观切换，先不改布局。
2. 顶栏、设置弹层、空状态。
3. 添加接口框上移，用例框头部重排，全部展开收起，复制全部。
4. 最近打开，业务域下拉，删除系统收进更多。
5. 原生菜单。
