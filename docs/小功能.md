# 小功能

只补日常会卡住的几处。不改表，不执行请求，不加环境变量。

## 搜索能落到接口

现在搜索只藏左侧系统。右侧仍停在上次选中的系统，并列出它的全部接口。命中的接口只有碰巧在这个系统里才会展开。

查询不为空时：

- 左侧只留命中的系统。系统名、业务域、说明、方法、路径、用例文本，任一包含即可。
- 系统下面列出命中的接口，一行是「方法 + 路径」。点这一行：选中该系统，展开该接口，滚到它。
- 当前系统不在命中里时，自动选中第一个命中的系统。
- 右侧只显示命中的接口，并展开。
- 查询清空后恢复完整列表，接口回到默认收起。

## 记住上次的系统

启动时不再总是打开第一个系统。切换系统时把系统 id 记在本机。下次打开，这个系统还在就继续停在它上面，否则打开第一个。

和 curl 底色、字号放在同一处本机记录里，不写入 `library.db`。

## 用例用第一行注释当标题

用例框标题现在只有「用例 1」。同一路径下多条 curl 时，必须展开才能分辨。

标题取用例正文里第一条以 `#` 开头的行，去掉 `#` 和两侧空白。没有这种行时仍显示「用例 N」。

要起名，就在 curl 上面写一行，例如 `# 查库存`。正文仍是原来的 curl，复制出去的内容不变。不给用例加新字段。

## 同名系统不重复建

添加系统时，名称去掉首尾空白后与已有系统完全相同，就不新建。直接打开那个系统，状态栏写「已有这个系统」。比较方式和导入时按系统名合并一致，区分大小写。

业务域留空时，按导入用的同一套前缀归类：`plan-` 计划，`scm-` 供应链，`ddmc-` 和 `greatwall` 采购，`risk-control` 风控，`sku-` 商品，`pms-` PMS，`abtest` 实验，`algo-` 算法，名称含「集成测试」归集成测试，其余归其他。用户填了业务域就用填写的。

## 删除入口要确认

入口上的 `×` 现在点下去就删。改成和其他删除一样，先弹出确认，文案是「删除入口 {名称}？」。取消则保留。

## 路径可以选中

接口标题行里，点方法或路径文字以外的区域仍是展开和收起。路径文字可以用鼠标选中，不会展开或收起。

## 搜索快捷键

`Command+K` 或 `Ctrl+K` 把焦点放到左侧搜索框，并选中已有文字。
