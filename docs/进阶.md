# 进阶

两件事。入口从标签改成能维护的「环境与链接」；再补一批让它真正能当 API 手册用的功能。

## 一、环境与链接

### 现在的问题

入口只有名字和地址，显示成一排标签。改不了，排不了序，分不清哪个是发布页、哪个是文档。更重要的是没有和用例发生关系：用例里的主机名和入口里的环境名各管各的。

### 拆成两类

**环境**：一个可部署的环境。字段：

- 名称：`TE`、`TEHW`、`SHHW1PE`
- 主机：curl 要打的地址前缀，例如 `https://scm-po.te.ddmc.com`。可以为空
- 发布页：paas 的环境页地址。可以为空
- 备注：一句话，例如「联调用」

**链接**：和环境无关的页面。字段：名称、地址、备注。例如 yapi、日志、监控、配置中心。

数据仍放 `links` 表，加三列：`kind`（`env` 或 `doc`）、`host`、`note`。`label` 继续当名称，`url` 对环境来说就是发布页。已有数据升级时，`url` 含 `environment?tab` 或 `env=` 的归环境，其余归链接。

### 界面

系统说明下面一个「环境」卡片，再一个「链接」卡片。每张卡片是行列表，不是标签。

环境一行从左到右：名称（加粗）、主机（等宽，灰）、备注（灰）、操作。操作平时淡色，悬停显示：

- 打开：有发布页就用浏览器打开
- 复制主机
- 编辑
- 删除：要确认

链接一行：名称、地址（截断，悬停显示全文）、备注、操作：打开、复制地址、编辑、删除。

编辑在行内完成：点编辑，这一行变成输入框，回车保存，Esc 取消。新增在列表末尾一行「+ 添加环境」「+ 添加链接」，点开同样是行内输入。

排序：行左侧有拖动把手，拖动改变 `position`。

主机输入框带候选：扫描这个系统所有用例里的 `https?://主机`，去重后列出，点一下填入。首次打开环境卡片时，如果某个环境还没有主机，而候选里恰好有一个主机包含该环境名的小写（`tehw` 对应 `scm-po.tehw.ddmc.com`），显示「用这个？」一键填入，不自动改。

### 环境和用例打通

用例框头部的「复制」旁边加一个下拉「复制到…」，列出有主机的环境。选一个，把用例里的 `https?://主机` 换成该环境的主机后复制，原文不动。只有一个环境有主机时下拉退化成一个按钮「复制到 TE」。

用例头部现在显示的主机名，如果能匹配到某个环境的主机，就显示环境名（`TEHW`）而不是原始主机，并带一个小色点。匹配不到仍显示主机名。

## 二、整体升级

按价值和成本排序。前三组是必做，后面按需。

### 1. 变量

同一个 token 或 cookie 出现在几十条 curl 里。过期后要一条条改。

系统上加「变量」卡片：名称、值、是否敏感。敏感值在界面上打码，点眼睛才显示。表 `variables(id, system_id, name, value, secret, position)`。

用例里用 `{{name}}` 引用。复制、运行、「复制到…」时替换成当前值。框里原文保留 `{{name}}`，高亮成单独一种颜色。没定义的变量高亮成红色。

「设为变量」：在用例框里选中一段文字，右上角出现「设为变量」，输入名字后把该系统所有用例里完全相同的文本替换成 `{{name}}`，并创建变量。这一步要确认，并显示会改几条。

### 2. 运行

用例框头部加「运行」。把替换过变量的命令交给系统 shell 执行（macOS、Linux 用 `sh -c`，Windows 用 `cmd /C`），30 秒超时。结果显示在该用例框下面的结果区：

- 第一行：退出码、耗时、响应大小
- 正文：stdout。如果是 JSON 自动格式化，并可折叠层级
- stderr 单独一段，默认收起
- 操作：复制结果、清空、再次运行

结果只留在内存，不写库。同一时刻一个用例只跑一个，运行中按钮变成「停止」。

这不是把应用做成 Postman，只是省掉切到终端粘贴的那一步。命令原封不动交给 shell，和在终端里跑一样。

### 3. 快速跳转

`⌘P` 打开命令面板。输入时模糊匹配系统名、方法、路径、用例标题，最多显示 20 条，上下键选择，回车跳转。条目格式：

- 系统：`scm-po-service · 供应链`
- 接口：`POST /api/po/create · scm-po-service`

最近跳转过的放最上面。Esc 关闭。侧栏搜索保留，用来筛选列表；面板用来直达。

### 4. 接口备注、收藏、修改时间

`apis` 加 `note`、`starred`、`updated_at`。`cases` 加 `updated_at`。

- 接口标题行下面一行灰字显示备注，点击编辑。可以写「幂等」「需要 header x-tenant」这类事
- 标题行加星标。收藏的接口排在该系统接口列表最前面，侧栏「最近」下面多一组「收藏」
- 用例头部最右边显示「3 天前」，悬停显示具体时间。改动内容时更新

### 5. 格式化和结构视图

用例头部加「格式化」：把一行 curl 拆成一个参数一行，`\` 续行，JSON 体缩进两格。写回原文，可以用「还原」撤销，直到下一次编辑。

用例框加「结构」开关，开后在代码区右侧显示解析结果：方法、完整 URL、查询参数表、请求头表、请求体（JSON 高亮）。只读，用来看清楚参数，不用来编辑。解析失败显示原因，比如「引号没闭合」。

### 6. 移动与合并

- 用例可以「移动到…」别的接口，接口可以「移动到…」别的系统。选择器复用 `⌘P` 的面板
- 导入时同一路径大小写或末尾斜杠不同造成的重复接口，标题行显示「可合并」，点击合并用例并保留先出现的那条

### 7. 导出和备份

- 「导出这个系统」：生成一份 Markdown，格式和导入的文档一致，可以回到原来的目录
- 「备份全部」：把整个库导出为一个 JSON 文件；「从备份恢复」：选文件覆盖，要确认
- 设置里加「每次启动自动备份到数据目录 `backups/`，保留 7 份」开关，默认开

### 8. 键盘

接口列表支持焦点：`↑` `↓` 在接口间移动，`→` 展开，`←` 收起，`Enter` 聚焦第一个用例框，`⌘C` 在接口行上复制路径。用例框里 `Esc` 回到接口行。所有快捷键在帮助菜单里列一张表。

### 9. 搜索语法

侧栏搜索和 `⌘P` 都支持前缀：`post:` 只匹配方法，`path:` 只匹配路径，`sys:` 只匹配系统名，`#` 开头只匹配用例标题。没有前缀保持现在的全文匹配。

## 数据变更汇总

- `links`：加 `kind TEXT NOT NULL DEFAULT 'doc'`、`host TEXT NOT NULL DEFAULT ''`、`note TEXT NOT NULL DEFAULT ''`
- `apis`：加 `note TEXT NOT NULL DEFAULT ''`、`starred INTEGER NOT NULL DEFAULT 0`、`updated_at INTEGER NOT NULL DEFAULT 0`
- `cases`：加 `updated_at INTEGER NOT NULL DEFAULT 0`
- 新表 `variables(id TEXT PRIMARY KEY, system_id TEXT REFERENCES systems ON DELETE CASCADE, name TEXT, value TEXT, secret INTEGER, position INTEGER)`

启动时用 `PRAGMA table_info` 检查列，缺的用 `ALTER TABLE ADD COLUMN` 补上。模型字段全部 `serde(default)`，旧数据直接读。
